# Как редактировать сайт

Сайт лежит в папке `portfolio` репозитория `rin`. Все пути ниже указаны внутри этой папки.

Все тексты сайта лежат в двух файлах:

- `content/en.yml` — английская версия (главная страница `/`);
- `content/ru.yml` — русская версия (страница `/ru`).

Код трогать не нужно. Меняете текст в YAML, сохраняете, и через минуту-две Vercel сам пересобирает сайт.

## Как поменять текст прямо на GitHub

1. Откройте файл `content/ru.yml` (или `en.yml`) на github.com.
2. Нажмите карандаш ✏️ справа сверху.
3. Поменяйте текст.
4. Нажмите **Commit changes** → **Commit changes**.
5. Через 1–2 минуты изменения будут на сайте.

Если сохранили файл с ошибкой, Vercel не опубликует новую версию, и на сайте останется предыдущая. Ошибку покажет вкладка Deployments в Vercel.

## Частые задачи

**Добавить место работы.** В `experience → jobs` скопируйте блок одного места целиком, от `- role:` до последнего пункта, и вставьте выше или ниже. Порядок на сайте такой же, как в файле.

```yaml
    - role: Head of Marketing
      company: Новая компания
      dates: мар 2027 — сейчас
      place: Москва            # необязательно
      about: Чем занимается компания   # необязательно
      logo: "/images/logos/new.svg"     # необязательно
      points:
        - Первое достижение
        - Второе достижение
```

**Удалить место работы или кейс.** Удалите весь его блок, от строки с `- ` до начала следующего.

**Добавить кейс.** В `cases → items` скопируйте блок кейса от `- category:` до `tags:`.
- `category` — к какой вкладке фильтра относится кейс (`perf`, `abm`, `gtm`, `startup`). Новую вкладку добавьте в `filters`.
- `color` — цвет шапки карточки: `yellow`, `blue`, `green` или `pink`.
- `image` — обложка, например `"/images/cases/my-case.png"`. Пусто — без обложки.
- `link` — ссылка «Читать подробнее», если кейс где-то опубликован.

**Скрыть или переставить секцию.** В начале файла есть список `order`. Удалите строку, и секция пропадёт. Поменяйте строки местами, и секции поменяются на странице. Не забудьте поправить меню `nav`.

**Поставить фото.** Загрузите фото в `public/images` (см. `public/images/README.md`) и впишите путь в `hero → card → photo`.

**Обновить резюме.** Замените файлы в `public/resume/` на новые с теми же именами:
- `Resume_Head_of_Marketing_EN.pdf`
- `Resume_Head_of_Marketing_RU.pdf`

Исходник русского резюме лежит в `resume/resume-ru.html`: его можно поправить и снова сохранить в PDF через «Печать → Сохранить как PDF» в браузере.

## Как загрузить картинку на GitHub

1. Откройте папку `public/images` на github.com.
2. **Add file → Upload files**, перетащите файл.
3. **Commit changes**.
4. Впишите путь в YAML, например `"/images/photo.jpg"`.

## Правила YAML, чтобы ничего не сломать

- Отступы только пробелами, по 2 на уровень. Табуляция ломает файл.
- Новый пункт списка начинается с `- `.
- Если в тексте есть двоеточие с пробелом (`: `), `#`, или текст начинается с кавычки, скобки, `%`, `@`, `*`, оберните его в двойные кавычки: `"Итог: +30% лидов"`.
- Строки вида `{ label: ..., text: ... }` — короткая запись. Внутри фигурных скобок текст с запятой обязательно в кавычках.
- Строки после `#` — комментарии, на сайт они не попадают.

Проверить файл можно на yamllint.com: вставьте текст и нажмите Go.

## Запуск на своём компьютере (необязательно)

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.
